# Книги для ридера (PWA)

Работает целиком в браузере и после первого открытия — **без интернета** (Service Worker кэширует приложение).

* **PDF с текстовым слоем → FB2** (крупный шрифт самого ридера): текст достаётся из файла, убираются колонтитулы и
  номера страниц, строки склеиваются в абзацы, переносы слов «лечатся».
* **PDF-сканы, схемы, формулы → картинки `.pgb`**: «по ширине текста» (несколько экранов на страницу, есть увеличение
  до 200% для мелкого шрифта) или «страница целиком» (один экран). Обрезка полей, дизеринг, предпросмотр «как на экране».
* **Цвет и градации.** Режим «Авто» (по умолчанию): текст остаётся чётким чёрно-белым, а картинки, фото и цветная
  графика рисуются в режиме «тон + цвет» — красный используется как средний тон только там, где у исходного пикселя
  есть цвет (тёплые тона, красный). Нейтральные (серые) фото получаются чисто чёрно-белыми, без красных точек.
  Красный текст и заголовки остаются красными. Другие режимы для сравнения на своих файлах:
  «Всё тон + цвет», «По яркости» (как раньше и как обложки в прошивке), «Палитра по цвету» (подход библиотек
  e-paper, например `epaper-dithering`), «Фото ч/б», «Только текст».
  Формат `.pgb` v3 хранит глубину по каждому экрану: цветные экраны 28 КБ, чёрно-белые 14 КБ (v2 ридер тоже читает).
* **EPUB / FB2 / PGB** отправляются на ридер как есть, без конвертации.
* Диапазон страниц — большую книгу можно грузить частями.
* «Панель ридера»: статус (книга, страница, батарея, память), переход на страницу, удаление книги.

## Состав репозитория (всё в КОРНЕ, без вложенных папок)

```
index.html  app.js  pgb.js  pdftext.js  service-worker.js  manifest.json
icon.svg  icon-192.png  icon-512.png  apple-touch-icon.png  .nojekyll
pdf.mjs  pdf.worker.mjs        <- из архива pdf.js (см. ниже)
```

### Какие файлы pdf.js брать — ВАЖНО

Из архива pdf.js берите **legacy**-сборку: `legacy/build/pdf.mjs` и `legacy/build/pdf.worker.mjs`
(в основном архиве `pdfjs-…-dist.zip` она лежит в папке `legacy/`; если её там нет — скачайте
`pdfjs-…-legacy-dist.zip` со страницы релизов github.com/mozilla/pdf.js/releases). Положите оба файла рядом с остальными,
имена не меняйте.

Почему не обычная папка `build/`: она использует новейшие функции JavaScript (например, `Map.getOrInsertComputed`),
которых нет в большинстве телефонных браузеров — рендеринг падает с ошибкой «… is not a function». Legacy-сборка работает везде.
`.map`-файлы и `pdf.sandbox.mjs` не нужны.

## Размещение на GitHub Pages

1. github.com → **New repository** (например, `pgb-converter`), доступ **Public**.
2. **Add file → Upload files** → перетащите ВСЕ файлы из списка выше → **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.**
4. Через 1–2 минуты появится адрес `https://<логин>.github.io/pgb-converter/`.
5. Откройте его на телефоне **с интернетом** и дождитесь загрузки страницы — приложение закэшировано.
6. Установка: Android/Chrome — меню ⋮ → «Установить приложение»; iPhone/Safari — «Поделиться» → «На экран Домой».
7. Проверка: авиарежим → открыть приложение → выбрать PDF → оно должно работать.

## Обновление

Изменили файл → в `service-worker.js` увеличьте номер в `CACHE_NAME` (сейчас `pgb-converter-v4`) → загрузите файлы в
репозиторий. Новая версия подтянется при следующем открытии с интернетом (иногда нужно закрыть и открыть приложение дважды).

## Прошивка

* `partitions_16mb.csv` рядом с `platformio.ini`, замените `main.cpp`, соберите, прошейте.
* После смены разметки флеша — один раз полный erase (`pio run -t erase`).
* Загрузка: подключитесь к Wi-Fi ридера → «Загрузить на ридер». Откроется вкладка `http://192.168.4.1/upload`;
  браузер может предупредить, что форма не защищена, — подтвердите. Дождитесь «Книга загружена».
* Запасной путь: «Скачать файл» → открыть `http://192.168.4.1` → загрузить файл через страницу ридера.

## Частые проблемы

* **Телефон не видит ридер** — Android уходит с Wi-Fi без интернета на мобильную сеть: выберите «Оставаться на этой сети»
  или выключите мобильные данные.
* **Статус ридера не читается** — браузер блокирует запросы из защищённого приложения к устройству по http (Chrome может
  спросить доступ к локальной сети — разрешите). Всё то же есть на странице ридера `http://192.168.4.1`.
* **Текст из PDF получился с мусором/не в том порядке** — сложная вёрстка (таблицы, формулы, сложные колонки): используйте
  режим «Картинки страниц».
* **В консоли ошибка про MIME-тип `.mjs`** — переименуйте `pdf.mjs`/`pdf.worker.mjs` в `.js` и поправьте имена в `app.js` и
  `service-worker.js`.
